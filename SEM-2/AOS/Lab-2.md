Motherboard Components

    RAM Slots: Long, narrow sockets on the motherboard designed to hold Memory Modules (RAM). They allow the CPU to access high-speed temporary data, and their number usually dictates the maximum memory capacity of the system.

    SATA Ports: Connection points used to link storage devices, such as Hard Disk Drives (HDDs) and Solid State Drives (SSDs), to the motherboard. They facilitate the transfer of data between the storage drive and the rest of the system.

    PCIe Slots: High-speed expansion interfaces used to connect hardware components like Graphics Cards (GPUs), sound cards, and NVMe SSDs. They come in different sizes (x1, x4, x8, x16) depending on the bandwidth required.

    Northbridge Chipset: A legacy controller hub that acted as the "bridge" between the CPU and high-speed components like RAM and the primary PCIe slots. In modern systems, these functions have been integrated directly into the CPU.

    Southbridge Chipset: The controller responsible for managing slower data paths on the motherboard, including USB ports, SATA drives, audio, and networking. It communicates with the CPU via the Northbridge (or the modern equivalent, the DMI).

    BIOS Chip: A small ROM chip that stores the Basic Input/Output System firmware. It is the first software to run when a computer is powered on, performing hardware initialization and handing off control to the operating system.

    CMOS Battery: A small, coin-shaped battery (usually a CR2032) that provides power to the BIOS/UEFI chip while the computer is off. This ensures the motherboard retains system settings, such as the date, time, and hardware configurations.

    Jumper Pins: Small metal pins used to bridge electrical circuits on the motherboard. By placing a plastic "jumper" over two pins, a user can manually reset BIOS settings, clear passwords, or configure specific hardware modes.

Cables and Connectivity

    DisplayPort Cable: A high-performance digital interface used primarily to connect a video source to a display. It supports high resolutions and refresh rates, and is capable of carrying audio and USB data alongside video.

    HDMI Cable: The standard digital connection for high-definition video and audio. It is widely used for connecting computers to monitors, TVs, and projectors, supporting both visual and multi-channel sound through a single cable.

    DVI Cable: An older digital video interface designed to transmit uncompressed video data. While it provided a bridge between analog VGA and modern HDMI, it typically does not carry audio signals.

    VGA Cable: A legacy analog connection recognizable by its 15-pin blue connector. Once the standard for monitors, it is now largely obsolete as it cannot match the clarity or resolution of digital signals.

    USB Cable: A universal interface used for data transfer and power delivery. It connects a vast array of peripherals—like keyboards, mice, and external drives—to a computer or charger.

    Ethernet Cable: A wired networking cable (often Cat5e or Cat6) used to connect computers to routers or switches. It provides a stable, high-speed internet or Local Area Network (LAN) connection.

    SATA Cable: An internal data cable used to connect storage drives to the motherboard's SATA ports. It features a distinct L-shaped connector to ensure proper orientation during installation.

    Power Cable: The main electrical cord that connects a computer's Power Supply Unit (PSU) or a monitor to a wall outlet, providing the necessary AC voltage to run the hardware.

Peripherals and Accessories

    VR Headset: A head-mounted display device that provides virtual reality for the wearer. It uses internal screens and motion tracking to immerse the user in a simulated 3D environment, often used for gaming or training.

    Capacitive Stylus: A pen-like tool that mimics the electrical properties of a human finger. It is used to navigate and draw on capacitive touchscreens, such as those found on modern smartphones and tablets.

    Graphics Tablet: An input device consisting of a flat, pressure-sensitive pad and a stylus. It allows artists to draw by hand, capturing the strokes and pressure levels to create digital art on a computer.

    USB Hub: A device that expands a single USB port into several, allowing multiple peripherals to be connected to a computer simultaneously. It acts much like a power strip for data connections.

    Wireless Presenter: A handheld remote used to control digital presentations (like PowerPoint). It typically features buttons to advance slides and often includes a laser pointer to highlight specific areas of a screen.
