# MACE_labs 

This repository archives my completed lab assignments and projects from my Master of Computer Applications (MCA) curriculum.

## Repository Structure

The projects are organized into clear folders based on the course:

| Folder Name | Content Focus | Primary Technology |
| :--- | :--- | :--- |
| **dsa** | Implementation of Advanced Data Structures and Algorithms. | **C Language** |
| **pyth** | Lab exercises and small projects focused on core Python programming concepts. | **Python** |
| **web** | Assignments covering front-end web development (HTML, CSS, JavaScript, React, etc). | **Web Technologies** |

---

## Getting Started

To explore any project, clone the repository and navigate to the desired folder:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/abhhiinv/MACE_labs.git](https://github.com/abhhiinv/MACE_labs.git)
    ```
2.  **Navigate:**
    ```bash
    cd MACE_labs/dsa 
    # OR
    cd MACE_labs/web
    #OR
    cd MACE_labs/pyth
    ```
3.  Refer to any internal documentation or comments within the code for specific instructions.
